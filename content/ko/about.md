# 이 위키에 대하여

[[ko/index|← 한국어 홈]] · [[it/about|Italiano]]

CHUCK WIKI는 음악과 영상, 가사와 기억, 철학과 레퍼런스를 선형 포트폴리오가 아니라 **연결된 세계**로 보여주기 위한 공개 아카이브입니다.

## 공개 원칙

1. 공개 승인을 받은 문서만 게시합니다.
2. 사적 대화, 일기, 사업 자료, API 키와 원본 개인정보는 게시하지 않습니다.
3. 번역은 단순 직역보다 작품의 말투와 의미를 보존합니다.
4. 문서는 완성본이 아니라 수정되고 연결되는 살아 있는 노드입니다.

## 언어 구조

한국어 문서는 `/ko/`, 이탈리아어 문서는 `/it/` 아래에 위치합니다. 대응 번역이 있을 때 문서 상단에서 서로 이동할 수 있습니다.
