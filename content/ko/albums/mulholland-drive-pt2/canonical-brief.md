# Pt.2 Canonical Visual Design Brief

[[ko/albums/mulholland-drive-pt2/index|← 앨범 허브]] · [[it/albums/mulholland-drive-pt2/canonical-brief|Italiano]]

> 이 문서는 2026-08-21 CHUCK이 강윤재에게 실제 전송한 `MULHOLLAND DRIVE PT.2 — Visual Design Listening Package`를 공개용으로 정리한 **Pt.2 최우선 정본**이다. 이후 LLM Wiki 해석과 비주얼 연구는 이 문서를 바꾸는 설정이 아니라 2차 확장 자료다.

## 1. 시리즈 안의 위치

《MULHOLLAND DRIVE》는 **총 4개의 파트**로 이어진다. Pt.2는 그 두 번째 작품이며, Pt.1의 마지막 장면인 `Fuck the System` 직후에서 시작한다.

Pt.1의 마지막에는 흰 공간 안에 무한한 스크린이 펼쳐진다. 주인공은 그 안에 구축된 매트릭스적 세계를 부수려 하지만 실패한다. Pt.2는 그 실패 이후, 절망 속에 남겨진 상태에서 죽음에 가까워지는 여정을 다룬다.

## 2. 시작과 끝의 정본 서사

`Fuck the System`은 단순히 “시스템에 저항한다”는 뜻을 넘어, **시스템을 fuck한다는 성적 이미지**로 표현된다.

그 충돌 직후 찾아오는 **사정 후의 공허와 현자타임**이 첫 트랙 `then the post-nut void`의 출발점이다.

Pt.2 전체는 그 공허에서 시작해 점차 죽음에 가까워지는 과정을 **임사체험의 터널**처럼 통과한다. 마지막 트랙 `Migguragy`의 미꾸라지는 **검은 정자**를 상징하며, 터널을 헤엄치는 생명체이자 죽음 직전의 잔상처럼 등장한다.

앨범은 완전한 죽음이나 재탄생으로 결론내리지 않는다. **Pt.3가 본격적인 죽음 테마로 시작된다는 사실을 예고하며 종료**된다.

```text
무한한 스크린의 매트릭스
→ 시스템 파괴 실패
→ 시스템과의 성적 충돌
→ 사정
→ post-nut void
→ 임사체험의 터널
→ 검은 정자 / 미꾸라지
→ Pt.3의 죽음 테마 예고
```

이 서사는 장면을 그대로 그리라는 지시가 아니라, Pt.2가 **어디에서 시작하고 어디까지 가는지** 전달하기 위한 시작점과 종점이다.

## 3. 핵심 시각 콘셉트

> 존재했지만 기록에서 지워진 2000년대 심야 애니메이션. 오래된 투니버스 방송을 우연히 다시 틀었는데 화면 속 기억이 조금씩 망가져 있는 느낌.

실제로 존재했던 작품을 복원한 것 같지만 어디에도 원본이 남아 있지 않은 **가짜 유실 방송과 잘못 복원된 기억**이 중심이다.

## 4. 전체 분위기

- Y2K 한국 애니메이션 / 2000년대 투니버스 심야방송
- CRT, VHS, 캠코더와 저화질 디지털 노이즈
- shoegaze의 번짐과 emo의 감정적 과잉
- pixel art, RPG 메뉴, save file과 대화창
- 《릴리 슈슈의 모든 것》 같은 청춘의 빛과 잔상
- 선명한 현실보다 잘못 복원된 기억
- 현대적인 완성도보다 실제 존재했을 것 같은 가짜 유실 방송
- 흰 공간, 무한 스크린, 터널과 방송 종료 이후의 잔상

## 5. 디자인에서 찾는 것

- 4개 파트가 독립적이면서 나중에 하나의 시리즈였음이 드러나는 공통 단서
- Pt.1과 연결되는 반복 요소와 떡밥
- 앨범 전체를 묶는 로고와 타이포그래피
- 방송 캡처 또는 오래된 DVD 패키지 같은 표면
- 오류가 난 자막, time code, channel logo와 save slot
- 흰 공간과 무한한 스크린을 연상시키는 단서
- Pt.2의 시작과 끝을 연결하는 터널과 통과 감각
- 감정은 크지만 지나치게 설명적이지 않은 이미지
- “어릴 때 본 것 같지만 실제로는 존재하지 않는 애니메이션”이라는 감각

곡 내용을 직접 삽화로 옮기기보다, **이 음악이 존재하는 매체와 기억의 형태 자체**를 디자인한다.

## 6. 피하는 방향

- 일반적인 cyberpunk
- 지나치게 깨끗하고 매끈한 디지털 이미지
- 단순한 VHS filter
- 곡 내용을 그대로 설명하는 일러스트
- 흔한 dark/gothic 앨범 커버
- 레퍼런스 이미지의 직접 복제·조합
- 성적·죽음 상징을 지나치게 직접 설명하는 이미지

## 9. 강윤재의 수신과 작업 상태

강윤재는 해당 내용을 듣고 만든 첫 이미지를 **“캔버스 같은 맨 밑 레이어”**라고 설명했고, 이후 디벨롭은 별도 제작 범위를 합의해 진행하기로 했다. 따라서 이 문서는 외부 해석이 아니라 실제 커버 작업의 입력값으로 사용된 브리프다.
