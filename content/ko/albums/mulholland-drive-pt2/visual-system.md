# Pt.2 Visual System

[[ko/albums/mulholland-drive-pt2/index|← 앨범 허브]] · [[it/albums/mulholland-drive-pt2/visual-system|Italiano]]

> **자료 계층:** 시작·종점·트랙 순서·시그니처 색은 [[ko/albums/mulholland-drive-pt2/canonical-brief|2026-08-21 강윤재 전달 브리프]]가 정본이다. 이 페이지의 장면 은행과 물리 열화 공정은 그 정본을 실행하기 위해 이후 Vault 연구에서 확장한 **2차 제작 문법**이다.

> Pt.2의 영상은 애니메이션을 만드는 일이 아니라 **잃어버린 방송 테이프를 발굴한 척하는 일**이다.

AI가 만든 매끈한 이미지는 완성본이 아니다. CRT, JVC, 인화지, 재촬영과 세대 손실을 통과하며 비로소 **누군가의 방과 몸을 거쳐온 증거**가 된다.

## 여섯 개의 핵심 명제

### 1. Lost broadcast — 지금 만든 것이 아니라 발굴된 것

모든 영상에는 최소 하나의 방송 흔적이 남는다.

- 4:3 프레임
- 코너 타임스탬프
- 가짜 편성표와 채널 ID
- `2004. 01:37 / 방영 기록 없음`
- 신호가 끊긴 자막과 종료 기록

실제 방송사 로고·범퍼·애니 클립은 사용하지 않는다. 목표는 복고 재현이 아니라 **존재하지 않았던 프로그램의 증거를 위조하는 것**이다.

### 2. CRT ghost-memory — 열화는 경로의 증거

스캔라인과 노이즈는 필터가 아니라 영상이 거쳐온 물리적 경로다.

- 곡면 유리 반사
- phosphor glow
- barrel distortion
- 화면 재촬영에서 발생한 roll bar
- 저장→재생→재촬영으로 누적되는 generation loss

CapCut CRT preset만 얹고 끝내지 않는다. 최종 클립은 적어도 한 번 실제 화면을 통과한다.

### 3. Y2K anime — CHUCK만 다른 그림체

세계는 애니메이션처럼 보이지만 CHUCK은 같은 해상도에 속하지 않는다.

- 실사 배경 + 픽셀 인물
- 저해상도 실루엣 + 지나치게 구체적인 방
- 다른 사람은 실사인데 CHUCK만 먹칠된 자리
- 얼굴이 캐릭터보다 누락 파일처럼 보이는 구조

특정 만화의 캐릭터와 서사를 복제하지 않고 **주인공만 다른 표기 체계에 속한다는 원리**만 가져온다.

### 4. Shoegaze distance — 흐림이 아니라 가독성 편곡

모든 장면을 흐리게 만들면 preset이 된다. Pt.2의 shoegaze는 특정 순간에만 정보가 사라지는 편곡이다.

- 훅 진입 0.5~1초에만 bloom
- 가장 아픈 문장에서 초점이 다른 곳으로 빠짐
- 노이즈 벽 뒤로 목소리와 자막이 절반 숨음
- 보이는 것이 줄어들수록 감정이 커지는지 확인

### 5. Pixel RPG UI — 차갑게 대신 말하기

직접 말하면 과잉 고백이 되는 문장을 상태창이 무표정하게 대신한다.

```text
MAYDAY 전송됨 … 응답 없음
LOCATION: 가지 못할 섬
STATUS: UNHEALED
ITEM: 다 녹은 얼음
SCORE: —
LAYER 03 / LAYER 04 / LAYER 05
```

게임 UI는 곡당 최대 세 번. 실제 게임의 폰트·문구·효과음을 복제하지 않고 CHUCK의 언어에서 파생한다.

### 6. JVC evidence — 몸이 실제로 있었다는 지분

JVC Everio GZ-MG650R은 고화질 카메라가 아니라 기억을 손상시키는 악기다.

- 방, 손, 발, 창문, 밤과 걷기
- autofocus hunting과 auto-gain의 흔들림
- 얼굴 정면보다 인물이 지나간 자리
- 현장 룸톤과 카메라가 따라가지 못한 동작

원본 MOD/MPEG-2는 영구 보존하고 편집은 변환 복사본으로만 한다.

## 매체와 표현의 조합

한 장면에는 매체 한 개와 표현 한 개면 충분하다.

| 매체             | 표현                      |
| ---------------- | ------------------------- |
| lost broadcast   | Y2K anime mismatch        |
| CRT ghost-memory | shoegaze readability loss |
| JVC evidence     | pixel RPG UI              |

세 개 이상을 동시에 넣으면 장면이 아니라 무드보드가 된다.

## 정본 색상과 보조광

| 계층     | 명칭            | 값                | 역할                                 |
| -------- | --------------- | ----------------- | ------------------------------------ |
| **정본** | CHUCK PURPLE    | `#5E2CA5`         | 시리즈 연결, 초월·내면·왜곡의 신호   |
| **정본** | CHUCK RED       | `#F04A52`         | 충돌, 경고, 채점선과 포인트          |
| **정본** | CHILDHOOD BLACK | `#060606`         | 앨범의 기본 암부와 삭제된 기록       |
| 보조광   | 흰 공간         | `#E6E2D8`         | Pt.1의 무한 스크린 공간, 종이와 자막 |
| 보조광   | CRT blue-green  | `#1E3A38–#243F4A` | 화면 재촬영에서 발생하는 광원        |

보조광은 별도 시그니처 컬러가 아니다. CHUCK PURPLE·RED·CHILDHOOD BLACK을 매체 안에서 보이게 하는 환경값이다. 검은비 역시 색상보다 역광 속 세로 운동으로 처리한다.

## 반복 장면 은행

- **채널 전환:** CRT 켜짐 → 편성표 → `방영 기록 없음`
- **흰 방과 검은 옷:** 해가 떠 있는데도 어둡게 노출된 기본 상태
- **덧칠하는 손:** 껍질 위에 검은 레이어가 쌓임
- **부재중 수신함:** 번호만 있고 내용은 없는 메시지
- **다 녹은 얼음:** 시간이 지나갔지만 아무도 마시지 않은 잔
- **창문으로 만든 섬:** 먼 불빛 하나를 도달 불가 좌표로 기록
- **안 낫는 친구들:** 같은 방에서 아무도 서로를 보지 않음
- **붉은 채점:** 점수 없이 사선만 그어지는 판정
- **검은비 크레딧:** 창 위의 물줄기와 작은 세로 자막
- **터널 ×3:** 같은 걷기가 반복될수록 화질과 목소리가 닳음
- **개기일식:** 3분 동안 빛과 딕션이 검은연기로 사라짐

## 제작 파이프라인

```text
AI 이미지 후보 생성
→ 12장 중 6장만 선택
→ 일부는 인화해 손으로 재촬영
→ 일부는 3~4초 image-to-video
→ 화면에 재생하고 JVC/폰으로 재촬영
→ 저장·재생·재촬영을 1~2세대 반복
→ 실제 방·손·걷기 촬영분을 섞음
→ 4:3, hard cut, 작은 자막과 UI로 조립
→ 비트보다 들숨과 날숨에 컷을 맞춤
```

매끈한 생성은 재료 단계다. 저작권과 인간성은 AI를 쓰지 않았다는 선언이 아니라 **무엇을 선택했고, 어떤 오류를 격리했으며, 어느 세대에서 멈췄는지**에 남는다.
